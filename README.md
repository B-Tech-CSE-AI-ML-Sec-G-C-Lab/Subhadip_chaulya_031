## 📖 About This Repository

This repository contains my C and C++ laboratory assignments for **CSE12106: Principles of Programming Language Lab** at Adamas University.

Each assignment is stored in its own dated folder, with a separate source file for each question.

Topics include procedural programming, functions, arrays, strings, structures, classes and objects, constructors, static members, friend functions, inheritance, polymorphism, abstract classes and exception handling.

## 🛠️ How to Compile and Run

Compile the program from its respective assignment folder using GCC/MinGW for C or G++/MinGW for C++.

### C Program

```bash
gcc Q1.c -o Q1
```

### C++ Program

```bash
g++ Q1.cpp -o Q1
```

### Run the executable in Windows PowerShell

```powershell
.\Q1.exe
```

### Example for a C++ assignment

```bash
cd "Assignment_10(03.11.26)"
g++ Q1.cpp -o Q1
.\Q1.exe
```
